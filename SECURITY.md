# Security policy

Do not report vulnerabilities in public GitHub issues and do not attach credentials, private Wiki content, generated indexes, or personal data.

Use GitHub's **Report a vulnerability** / private Security Advisory flow for this repository. If private reporting is not available, contact the repository owner through the GitHub profile without disclosing exploit details publicly.

Treat path traversal, symlink escape, unsafe snapshot promotion, integrity-check bypass, packaged-vendor substitution, secret exposure, and any write to the source Markdown root as security-sensitive.

Supported security fixes target the latest release on Python 3.9+ for Linux and macOS. Windows is not currently supported.
